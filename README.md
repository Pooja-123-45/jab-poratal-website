# HireHub - Job Portal

HireHub is a responsive web-based job portal that connects job seekers with recruiters. It allows candidates to create profiles, search and apply for jobs, manage resumes, and track applications. Recruiters can post jobs, manage applications, and shortlist or reject candidates.

## Features

### Job Seeker
- User registration and login
- Dynamic user profile
- Search and filter jobs
- Apply for jobs
- Track application status
- Create and update resume
- Manage skills and experience

### Recruiter
- Recruiter dashboard
- Post new jobs
- Edit and delete job postings
- View applicants
- Shortlist or reject candidates
- Manage company profile

### Admin
- Admin dashboard
- View total users
- View companies
- Monitor job postings
- Monitor applications

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
